# 세울까말까 — 개발과 검증 계획

기준일: 2026-11-07 · 전체 화면·기능 프론트 데모 구현 완료

[공통 정책](00_공통정책.md)과 기능 명세를 구현하기 위한 기본안이다. 도구·라이브러리 선택안은 사용자 확정 제품 정책과 구분하며, 버전 호환성은 개발 시작 후 확인한다.

폴더 구조는 [폴더 구조 명세](07_폴더구조.md)를 따른다. 초기 기반 위에 기획 문서의 전체 화면·기능을 데모로 구현했다. 실제 버전·명령·브랜치·초기 실행 검증은 [협업과 초기 세팅](08_협업과_초기세팅.md)에 관리한다. 아래 전체 제품 기능 검증표와 초기 기반의 확인 결과는 구분한다.

## 1. 구현 기본안

| 항목        | 기본안                                                                                   |
| ----------- | ---------------------------------------------------------------------------------------- |
| 프로젝트    | React Native + TypeScript + Expo 전용 개발 빌드                                          |
| 탐색        | Expo Router의 탭·스택. 로그인·차량 등록 조건을 공통 진입 경계에 적용                     |
| 공통 상태   | React 공통 상태로 계정·차량·현재 주차·설정·데모 응답 연결. 화면별 중복 타이머·모달 방지  |
| 기기 저장   | AsyncStorage에 데모 상태 보관. 앱 소유 키 구분, 늦은 쓰기·중복 저장·삭제 상태 복원 방지  |
| 데이터 계층 | 화면과 모의 조회·제출·지연·실패 주입·시연 제어 분리. 내부 모델과 API 계약 구분           |
| 지도        | 공통 좌표 모델과 지도 표시 분리. SDK별 카메라·마커/구역·제스처는 추후 연결 부분에서 처리 |
| 자산        | Noto Sans KR와 Figma 토큰. 임시 로고·아이콘을 교체 가능한 별도 자산으로 관리             |
| 빌드        | 로컬 Android 개발 빌드. Expo Go만으로 전체 네이티브 기능 실행을 전제하지 않음            |
| 패키지      | npm 기본. 개발 시작 시 안정 Expo SDK와 호환되는 의존성 선택·버전 고정                    |
| 시간        | 숫자·게이지·만료를 같은 시간 기준으로 계산. 앱 복귀·재실행 시 경과시간 반영              |
| 작업 취소   | 재연결·초기화·탈퇴 이후 응답과 예약 작업을 무효화. 기존 완료 기록 보관                   |

AsyncStorage는 현재 데모 상태 보관용이다. 실제 인증 토큰의 저장 정책은 인증 연동 시 별도로 정한다. 클라우드 빌드 서비스·유료 플랜은 선행 조건으로 두지 않는다. 실제 기기 기능에 따라 Android 네이티브 코드 연결을 검토한다.

## 2. 환경과 화면 검증 조합

| 대상         | 검증 계획                                                                |
| ------------ | ------------------------------------------------------------------------ |
| 실기기       | Galaxy Z Flip3 / Android 15 / 완전히 펼친 세로                           |
| 에뮬레이터   | Android 15 기본, 논리 폭 320/360/390/412와 짧은·긴 화면                  |
| 글자 배율    | 1.0/1.3/1.5 기본 조합                                                    |
| 우선 점검    | 긴 주소·장소명, 설문, 5탭 라벨, 시간 연장, 기록 필터, 키보드·시스템 영역 |
| 버전         | 선택 Expo SDK·React Native·Router·저장 라이브러리 호환 버전 기록         |
| Android 지원 | 선택 SDK·의존성의 공식 범위에 맞춰 최소 지원 버전 기록                   |

폭·글자 배율은 검증 기본안이며 Flip3 실측치나 모든 기종 지원 보장이 아니다. 실제 창 크기·화면 확대·글자 배율을 확인하고 검증·미검증 범위를 기록한다.

Node·npm·JDK·Expo 호환성을 확인하고 Android APK를 빌드했다. API 35 에뮬레이터를 준비했으며 Flip3 실기기는 미연결이다. 정확한 환경과 검증 상태는 협업 문서를 기준으로 한다.

## 3. 구현 전 디자인 검토

개별 화면 정밀 검토를 마치고 구현에 반영했다.

- [x] 개별 화면 상세 컨텍스트·스크린샷·치수 대조
- [x] 1단계 상세는 실제 콘텐츠 노드 `232:2185` 기준으로 배치
- [x] 현재 정책으로 교체할 서비스명·라벨·권한·타이머·필터 반영
- [x] 독립 원본이 없는 로딩·오류·지역 안내·설문 등을 기존 토큰·컴포넌트로 보완
- [ ] 아이콘 원본 SVG 자산 사용(현재 Ionicons로 대체)

디자인 목록·토큰은 [화면 및 디자인](01_화면_및_디자인.md)에 관리한다. 원본 관찰을 기능 추가나 검증 완료로 간주하지 않는다.

## 4. 구현 후 검증표

아래 표는 전체 제품 기능 검증이다. 에뮬레이터에서 직접 실행한 항목과 사용자 테스트·미검증 항목을 구분한다.

| 구분        | 확인 내용                                                                 | 상태                                                   |
| ----------- | ------------------------------------------------------------------------- | ------------------------------------------------------ |
| 초기 진입   | 로그인·안내·차량 등록, 실패·재시도, 미등록 홈 우회 차단                   | 확인 (로그인 실패·재시도, 권한 단계 포함)              |
| 상태 복원   | 재실행·재로그인 시 차량·설정·기록·진행 상태 복원                          | 확인 (강제 종료 후 진행 복원 포함)                     |
| 타이머      | 15초·게이지, 터치 정지·남은 시간 재개, 연장·재측정, 중복 확정 방지        | 15초·자동 확정 확인 / 터치 정지·연장은 사용자 테스트   |
| 시간 경계   | 잠금·다른 앱·홈 이동·재실행 후 경과시간 및 응답 대기                      | 홈 이동·재실행 확인 / 잠금·다른 앱은 사용자 테스트     |
| GPS·지역    | 좌표 표시·보정, 실패 시 자동 확정 OFF, 수동 지정, 용인시 외 차단          | 확인                                                   |
| 횡단보도    | 수동·자동 동일 모달, 응답 전 분석 금지, 닫힘 차단·수정 복귀 없음          | 확인                                                   |
| 재연결      | 위치·모달·분석 중 취소, 새 결과/기록 없음·늦은 응답 무시·이전 기록 유지   | 위치 선택 중 취소 확인 / 나머지 단계는 시나리오 준비됨 |
| 결과·기록   | 5개 결과 상태, 6개 필터, 기록 없음·필터 결과 없음                         | 확인                                                   |
| 기록 상세   | 당시 결과, 자동 재분석 없음, 동일 기록 재시도·취소, 필터·스크롤 복귀      | 확인                                                   |
| 지도·검색   | 예시 검색·빈 결과·좌표 선택, 건수 토글                                    | 확인 / 한글 검색 결과 선택은 사용자 테스트             |
| 주차장      | 반경·필터·거리순·목록/핀 갱신·빈 결과·보조 동작 미리보기                  | 확인                                                   |
| 사후 설문   | 대상·설정·응답·건너뛰기·뒤로 가기·중복 방지                               | 확인                                                   |
| 데이터 정리 | 로그아웃 접근 차단·보관, 차량 변경, 초기화·탈퇴, 읽기 실패 시 데이터 유지 | 확인                                                   |
| 화면 대응   | 폭·높이·글자 배율·키보드·시스템 영역에서 잘림·겹침 없음                   | 기본 폭(412dp) 확인 / 320·360 폭·글자 1.3·1.5 미검증   |
| 시연 경계   | 외부 연결 없는 전체 흐름, 시나리오가 실제 이용 화면·공통 상태 사용        | 확인 (D01~D10 시나리오 준비 UI)                        |
| 원본 일치   | 개별 화면·토큰·자산과 현재 기획 반영                                      | 확인 / 아이콘은 Ionicons 대체                          |

검증 환경: `Medium_Phone_API_37.0` 에뮬레이터(API 37, 412dp)와 사용자 직접 테스트. Galaxy Z Flip3 실기기는 미검증이다.

실제 OS 백그라운드 실행, 강제 종료·재부팅·시간 변경, 블루투스 수신·GPS·권한·지도 SDK는 [후속 연동 계획](03_API_연동_대기.md)에서 별도 검증한다.
