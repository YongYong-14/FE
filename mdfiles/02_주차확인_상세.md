# 세울까말까 — 주차 확인 상세

> 실제 데이터·권한·온보딩 기준: [온보딩과 실서비스 전환](12_온보딩과_실서비스_전환.md).
> 기준일: 2026-11-07

[공통 정책](00_공통정책.md)의 진입·지역·저장 조건을 적용한다. 차량 연결·위치는 실제 기기에서, 분석 결과는 서버에서 받는다.

## 1. 절차

`등록 차량 연결 해제 → 주차 추정 → 앱에서 위치 확인 → 수동 또는 자동 위치 선택 종료 → 횡단보도 응답 → 분석 → 결과·기록`

연결 해제는 주차 추정 이벤트다. 목적지 사전 입력은 필요하지 않으며, 다른 블루투스 기기의 연결 해제는 처리하지 않는다. 앱의 홈이 보이는 동안 새 연결 해제 건이 감지되면 별도 진입 버튼 없이 위치 확인 화면으로 자동 이동한다. 백그라운드에서는 화면을 강제로 띄우지 않고 홈 복귀 시 진행하며, 사용자가 뒤로 돌아온 진행 건은 이어가기 버튼으로 재진입한다.

| 단계               | 진입·동작                                                          | 다음 단계                                                             |
| ------------------ | ------------------------------------------------------------------ | --------------------------------------------------------------------- |
| 주차 추정          | 등록 차량 연결 해제 상태 보관, 홈에서 위치 확인 화면 자동 진입     | 위치 조회                                                             |
| 위치 조회          | 실제 GPS 위치 조회                                                 | 용인시 내 좌표 확보 시 위치 선택. 실패 시 수동 지정. 용인시 외는 안내 |
| 위치 선택          | 중앙 고정 핀 아래 지도를 움직여 좌표·주소 보정, 15초 타이머·게이지 | 버튼 또는 만료로 횡단보도 응답 대기                                   |
| 수동 지정          | 자동 확정 OFF. 주소 검색 후 지도로 세부 위치 조정                  | 용인시 내 위치의 수동 확인 후 횡단보도 응답 대기                      |
| 횡단보도 응답 대기 | 예/아니요 응답 확보                                                | 응답 후 분석                                                          |
| 분석               | 진행 표시, 모의 응답 처리                                          | 결과·리포트 및 기록                                                   |
| 취소               | 완료 전 등록 차량 재연결                                           | 진행 상태 정리 후 홈. 새 결과·기록 없음                               |

최초 위치 조회 중에는 확정할 좌표가 없으므로 타이머를 시작하지 않는다. GPS 확보 시 해당 좌표가 지도 중앙 핀 아래에 오도록 초기화한다. 핀은 지도 표시 영역 중앙에 고정하고 터치는 지도로 전달한다. 화면 문구는 `중앙 핀이 주차한 위치에 있나요?`, `지도를 움직여 중앙 핀에 주차한 위치를 맞춰 주세요`를 사용한다. 지도에서 조정한 위치도 지원 지역과 GPS 기준 200m 보정 제한을 확인한다.

지도 이동·확대 및 카메라 이동이 끝나기 전에는 확정하지 않는다. 지도가 멈추면 중앙 좌표의 실제 주소를 조회하고 최신 조회 결과만 선택 위치에 반영한다. 지도 조작·주소 조회 중에는 수동 확정 버튼과 자동 확정을 보류하고 타이머를 잠시 멈춘다. 주소 조회 실패 시 이전 주소로 확정하지 않고 지도 재조작·다시 측정을 안내한다. 확대만 하거나 최초 GPS 위치의 미세한 SDK 오차는 위치 보정으로 처리하지 않는다.

## 2. 위치 선택과 타이머

| 상황                        | 남은 시간             | 게이지·화면                             |
| --------------------------- | --------------------- | --------------------------------------- |
| 용인시 내 GPS 좌표 확보     | 15초 시작             | 가득 찬 게이지와 숫자                   |
| 시간 경과                   | 감소                  | 잔여 비율에 따라 부드럽게 감소          |
| 앱 내 터치·드래그 중        | 유지                  | 숫자·게이지 정지                        |
| 조작 종료                   | 남은 시간부터 재개    | 멈춘 위치에서 감소 재개                 |
| 화면 꺼짐·잠금·다른 앱 사용 | 경과시간 반영         | 만료 시 횡단보도 응답 대기              |
| `시간 연장`                 | 15초로 리셋           | 게이지 전체 복원. 손을 뗀 후 감소       |
| `이 위치가 맞아요`          | 종료                  | 선택 위치를 유지하고 횡단보도 모달      |
| 0초 도달                    | 종료                  | 위치 선택만 종료하고 횡단보도 응답 대기 |
| `다시 측정하기`             | 측정 중 정지          | 게이지 정지, 이전 만료 무효화           |
| 재측정 성공                 | 새 좌표로 15초 재시작 | 게이지 전체 복원                        |
| 재측정 실패                 | OFF                   | 수동 위치 지정·확인                     |
| GPS 확보 실패 후 수동 지정  | OFF 유지              | 위치 선택 후 버튼으로 확인              |

- 숫자·게이지·만료 판단은 같은 시간 상태를 사용한다. 게이지 비율은 `남은 시간 / 15초`다.
- 일반 조작은 시간을 초기화하지 않는다. 5초에서 조작했으면 5초부터 재개한다.
- `시간 연장`은 타이머 옆 작은 보조 버튼이다. 확정 전 반복 사용 가능을 기본안으로 두며 별도 횟수 제한은 정하지 않는다.
- GPS 정확도 15m 이내는 자동 확정하며, 15m 초과 50m 이하는 직접 확정한다. 50m 초과·측위 실패는 수동 지정한다.
- GPS 실패로 진입한 수동 경로는 검색·지도 조작 종료만으로 타이머를 켜지 않는다. 위치 지정 전에는 확정할 수 없다.
- 터치·드래그·다중 터치·취소·앱 상태 전환에서 정지·재개를 일관되게 처리한다. 실제 지도 연결 시 SDK 조작 이벤트도 연동한다.
- 수동 확정·만료·연장이 겹쳐도 위치 선택 종료는 한 번만 처리한다.

## 3. 횡단보도 확인 모달

**질문:** 주차하신 곳이 횡단보도 위 또는 횡단보도에서 10m 이내인가요?

| 항목                        | 정책                                                 |
| --------------------------- | ---------------------------------------------------- |
| 진입                        | 수동 확인 또는 15초 만료 후                          |
| 응답                        | 예 / 아니요                                          |
| 예                          | 직접 응답을 근거로 1단계 리포트를 표시               |
| 아니요                      | 부정 응답을 반영하고 다른 주차 위험 분석은 계속 진행 |
| 미응답                      | 응답 대기. 기본값 저장·질문 생략·분석 진행 없음      |
| 바깥 터치·Android 뒤로 가기 | 닫힘 차단                                            |
| 위치 수정 복귀              | 제공하지 않음. 위치 보정은 모달 진입 전까지          |
| 화면 잠금·다른 앱 이용      | 대기 상태 유지. 복귀 시 표시                         |
| 등록 차량 재연결            | 전체 진행 취소 규칙 적용                             |

위치 타이머는 모달 진입 시 종료한다. 모달에 별도 응답 제한 시간을 두지 않으며 `잘 모르겠어요` 선택지는 제공하지 않는다. 응답은 사용자 제공 정보로 표시한다.

`예`는 리포트와 기록의 분류를 함께 1단계로 바꾼다. 서버가 이미 1단계를 판정했다면 시설 근거를 유지하고 횡단보도 응답을 추가한다. `아니요`는 서버 판정을 유지하며 다른 위험 분석을 계속한다. 직접 응답을 GPS 측정 거리나 서버 판정으로 표시하지 않고 과태료를 임의로 만들지 않는다.

현재 API에는 횡단보도 응답 저장 항목이 없다. 응답과 원래 서버 결과를 계정별 기기 저장소에 보관하고 결과·기록 상세 재조회·재분석·단계 필터에 병합한다. 앱 데이터 삭제·다른 기기에서는 이 응답을 복원할 수 없다. 자동 위험 알림은 제공하지 않으며 결과·기록 리포트에만 반영한다.

문구 기준 참고: [도로교통법 제32조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1030974255). 실제 법적 판정·과태료 규칙은 후속 연동 시 근거와 함께 검토한다.

## 4. 뒤로 가기와 이어가기

- 모달 진입 전 위치 확인 화면의 뒤로 가기는 홈으로 이동하며 좌표·남은 시간·단계를 유지한다.
- 홈의 `주차 위치 확인 이어가기`로 돌아온다. 화면 재진입으로 시간을 리셋하지 않는다.
- 홈·다른 탭에서도 같은 진행 상태 하나를 사용한다. 앱 내 조작 중 정지·조작 후 재개 규칙을 유지한다.
- 홈에 있는 동안 만료되면 응답 대기로 전환한다. 홈에서 강제로 모달을 열지 않고 확인 화면 재진입 시 표시한다.
- 수동 지정 경로는 타이머 OFF를 유지한다.
- 횡단보도 모달이 열린 뒤에는 Android 뒤로 가기를 차단한다.

## 5. 완료 전 차량 재연결

위치 조회·위치 선택·수동 지정·횡단보도 응답 대기·분석 중 등록 차량이 재연결되면 현재 절차를 취소하고 홈으로 돌아간다. 홈에서 이어가기를 기다리는 건에도 적용한다.

1. 타이머·게이지·응답 대기·분석·진행 중 요청를 정리한다.
2. 해당 건의 이어가기·복원 상태를 제거한다.
3. 늦게 도착한 위치·분석 응답과 만료 처리를 무효화한다.
4. 새 결과·새 주차 기록을 생성하지 않는다.
5. 이전 완료 기록을 유지한다. 과거 기록 재시도의 취소도 원래 기록을 삭제하지 않는다.

분석이 시작됐어도 같은 취소 정책을 적용한다. 백그라운드에서는 앱을 강제로 열지 않고 복귀 시 취소 상태를 반영한다. 재연결을 실제 미주차의 증거로 해석하는 정책은 아니다.

## 6. 분석과 결과 저장

- 횡단보도 응답 후에만 분석한다.
- 위치·주차 이벤트·사용자 응답을 같은 진행 건으로 관리하며 중복 분석·중복 기록을 방지한다.
- 결과·저장 여부는 [공통 정책](00_공통정책.md)의 결과 분류를 따른다.
- 기존 기록의 재분석은 [기록 상세](01_화면_및_디자인.md)의 동작을 적용한다.
- 현재 진행과 과거 사후 설문이 겹치면 현재 위치 확인·분석을 우선한다.
- 실제 API 요청 취소·서버 저장·재분석 시간 기준은 후속 명세와 대조한다.

## 7. 재실행과 시간 복원

선택 위치·단계·자동 확정 사용 여부·시간 정보를 기기에 보관한다.

| 복원 상태                      | 동작                                                 |
| ------------------------------ | ---------------------------------------------------- |
| 자동 확정 사용·시간 남음       | 경과시간을 반영한 남은 시간부터 재개                 |
| 자동 확정 사용·시간 만료       | 횡단보도 응답 대기                                   |
| GPS 실패의 수동 지정           | 타이머 OFF 유지                                      |
| 횡단보도 응답 대기             | 응답 대기 유지. 미응답 분석 금지                     |
| 로그아웃 상태                  | 로그인 전 진행 화면 숨김. 재로그인 후 유효 상태 복원 |
| 취소·초기화·탈퇴로 정리된 상태 | 복원하지 않음                                        |

백그라운드 진입 시 터치 정지 상태를 계속 유지하지 않고 경과시간을 반영한다. 프로세스 종료 중 코드가 계속 실행됨을 전제하지 않으며, 복귀·재실행 시 시간과 진행 상태를 일치시킨다. 실제 백그라운드 실행·재부팅·시간 변경·기기 이벤트 수신은 후속 기기 연동 검증 대상이다.
