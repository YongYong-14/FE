# 세울까말까 — 화면 및 디자인

기준일: 2026-11-07

진입·지역·저장·결과 분류·화면 대응은 [공통 정책](00_공통정책.md)을 적용한다. 타이머와 취소·복원은 [주차 확인 상세](02_주차확인_상세.md)를 따른다. 아래의 세부 배치·보조 버튼 동작은 기존 기획을 구성하는 구현 기본안이다.

## 1. 화면 구조

| 구분           | 화면                                                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 초기 진입      | 스플래시, 로그인, 권한 안내·온보딩, 차량 등록                                                                            |
| 하단 5탭       | 홈, 지도, 주변 주차장, 기록, 마이페이지                                                                                  |
| 별도 화면·모달 | 위치 확인, 횡단보도 질문, 분석 결과·리포트, 기록 상세, 사후 설문, 차량 변경, 약관·개인정보 안내, 확인·오류·데모 미리보기 |
| 시연 도구      | 마이페이지 하단의 데모 설정                                                                                              |

위치 확인·리포트·기록 상세는 탭 위의 별도 화면으로 구성한다. 상세에서 뒤로 가면 원래 목록·탭으로 복귀한다. 위치 확인의 뒤로 가기는 진행 상태를 유지하는 별도 규칙을 적용한다.

### 지도와 장소 검색

- 지도는 Figma 스타일의 단순 배경·핀·위험 구역과 제한된 위치 선택을 재현한다. 넓은 지도 엔진이나 완전한 이동·확대축소 기능을 직접 만들지 않는다.
- 지도 탭·위치 확인·GPS 실패 후 수동 지정은 공통 용인시 예시 장소 목록을 사용한다.
- 이름·주소로 목록을 필터링하고 결과 선택 시 좌표·핀을 전달한다. 검색 중·결과 없음 상태를 제공한다.
- 지도 건수 토글은 예시 구역·건수 표시를 제어한다. 실제 집계나 분석 요청으로 표시하지 않는다.
- 지도 표시와 타이머·모달·카드·탭은 분리한다. 위치·마커·구역은 공통 좌표 데이터로 관리한다.

### 주변 주차장

주차 위치를 기준으로 반경·필터를 적용하고 결과 없음 안내를 제공한다. 500m에서 결과가 없는 경우 1km 확대 안내와 재조회 흐름을 구성한다. 주차장 유형·거리·도보 시간·요금·운영 상태는 예시임을 구분한다. 별도 AI 추천 기능은 제공하지 않는다.

공유·길안내·외부 지도 검색은 선택 장소·좌표·예정 동작을 보여주는 앱 내부 미리보기 데모다. 실제 메시지 전송·시스템 공유·외부 지도 실행·경로 계산을 수행한 것으로 표시하지 않는다.

### 기록 상세

| 기록 상태        | 표시 내용                                | 재분석                        |
| ---------------- | ---------------------------------------- | ----------------------------- |
| 1단계·2단계      | 당시 위치·주차 시각·저장된 근거와 리포트 | 상세 진입만으로 실행하지 않음 |
| 확인된 위험 없음 | 당시 위치·주차 시각·완료 결과            | 상세 진입만으로 실행하지 않음 |
| 정보 부족        | 당시 정보, 미제공 항목·판단 제한 설명    | `다시 분석하기` 제공          |
| 분석 실패        | 당시 위치·주차 시각·실패 설명            | `다시 분석하기` 제공          |

- 초기 필터는 `전체`이며 좁은 화면에서는 가로 스크롤 행을 사용한다.
- 기록 자체가 없는 경우와 현재 필터의 결과가 없는 경우를 구분한다.
- 재시도 중 중복 요청을 막고 새 결과 확정 전 기존 저장 결과를 보관한다.
- 뒤로 가면 보던 필터·스크롤 위치로 복귀한다. 갱신 결과가 현재 필터와 다르면 해당 필터 목록에서 제외한다.
- 실제 과거 시점 재분석의 제공 범위는 추후 API 명세와 대조한다.

## 4. 리포트

주차 위치·시각·결과 상태, 위험 근거·출처, 제공 가능한 신고·단속 이력과 시간대 차트, 사용자 횡단보도 응답, 주변 주차장 진입을 표시한다.

정보 부족·분석 실패는 별도 설명과 재시도를 제공한다. 데이터가 없는 통계·근거·법정 수치는 미제공으로 구분한다. 실제 위험 계산은 수행하지 않으며, 1·2단계와 리포트 수치는 예시 데이터다.

## 5. 재탑승 사후 설문

| 항목                | 정책                                                                            |
| ------------------- | ------------------------------------------------------------------------------- |
| 대상                | 이전에 위험 리포트를 확인한 주차 건, 등록 차량 재연결, 앱 이용 중, 설문 설정 ON |
| 질문                | 이전 주차 위치에서 불법주정차 단속을 받으셨나요?                                |
| 응답                | 단속됨 / 단속 안 됨 / 아직 확인하지 못함                                        |
| 건너뛰기            | `이번엔 건너뛸게요` 또는 Android 뒤로 가기                                      |
| 건너뛰기 처리       | 응답 없이 닫고 같은 주차에는 다시 질문하지 않음                                 |
| 중복 제어           | 응답 완료·건너뛰기 상태를 주차별로 기기에 보관. 재실행·재로그인 후에도 유지     |
| 설정                | 최초 ON. 마이페이지에서 변경하며 기기에 유지                                    |
| 표시 기본안         | 기존 스타일의 앱 내부 모달. 바깥 터치로 닫지 않음. 내용에 맞는 높이·스크롤      |
| 진행 중 절차와 충돌 | 위치 확인·분석을 우선하고 과거 설문은 대기                                      |

건너뛰기는 설문 응답값이나 설정 OFF로 처리하지 않는다. 다음 대상 주차에는 기존 설정에 따라 새 설문을 제공한다. 취소된 현재 주차는 설문 대상이 되지 않으며, 이전 완료 위험 기록의 대상 여부는 별도로 판단한다. 응답은 주차별 데모 데이터로 보관하고 실제 제출·집계·학습은 후속 연동으로 둔다.
