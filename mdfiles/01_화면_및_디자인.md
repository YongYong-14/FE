# 세울까말까 — 화면 및 디자인

> 실제 데이터·권한·온보딩 기준: [온보딩과 실서비스 전환](12_온보딩과_실서비스_전환.md).
> 기준일: 2026-11-07

진입·지역·저장·결과 분류·화면 대응은 [공통 정책](00_공통정책.md)을 적용한다. 타이머와 취소·복원은 [주차 확인 상세](02_주차확인_상세.md)를 따른다. 아래의 세부 배치·보조 버튼 동작은 기존 기획을 구성하는 구현 기본안이다.

## 1. 화면 구조

| 구분           | 화면                                                                                                       |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| 초기 진입      | 스플래시, 로그인, 권한 안내·온보딩, 차량 등록                                                              |
| 하단 5탭       | 홈, 지도, 주변 주차장, 기록, 마이페이지                                                                    |
| 별도 화면·모달 | 위치 확인, 횡단보도 질문, 분석 결과·리포트, 기록 상세, 사후 설문, 차량 변경, 약관·개인정보 안내, 확인·오류 |

위치 확인·리포트·기록 상세는 탭 위의 별도 화면으로 구성한다. 상세에서 뒤로 가면 원래 목록·탭으로 복귀한다. 위치 확인의 뒤로 가기는 진행 상태를 유지하는 별도 규칙을 적용한다.

### 안전 영역(Safe Area)

- 화면 최상단의 `SafeAreaProvider`가 기기의 실제 상태바·카메라 영역·하단 시스템 탐색 영역을 측정한다. 첫 렌더는 초기 기기 측정값으로 시작한다.
- 로그인·온보딩·차량 등록 등 일반 화면은 공통 `Screen`에서 필요한 가장자리 여백을 처리한다. 기본 헤더가 있는 화면은 상단 여백을 중복 적용하지 않는다.
- 지도 배경은 화면 끝까지 채우고 검색창·뒤로 가기·설정·현 위치 등 조작 요소와 시트 본문만 안전 영역 안에 둔다.
- GNB가 있는 화면의 하단 시스템 여백은 GNB에서 한 번만 처리한다. 홈 시트·지도 범례·주차장 목록·기록·마이페이지에는 같은 하단 여백을 더하지 않는다.
- 위치 확인·리포트처럼 GNB가 없는 화면은 자체 시트에서 하단 여백을 처리한다. 내용이 길면 스크롤로 마지막 버튼까지 접근할 수 있다.
- 공통 모달은 별도 네이티브 창 안에서 안전 영역을 측정한다. 하단 모달 배경은 끝까지 채우되 마지막 버튼 아래에 시스템 여백을 확보하고, 중앙 모달은 네 가장자리 안에서 높이를 제한한다. 정렬 메뉴도 안전 영역 안으로 위치를 제한한다.
- Galaxy Z Flip3를 펼친 화면을 포함해 기기에서 받은 여백을 사용한다. 상태바·내비게이션 바 높이를 고정 숫자로 가정하지 않는다.

### 홈 지도와 하단 정보 패널

- 홈 상단의 감지 상태바와 설정 버튼은 제공하지 않는다. 설정은 GNB 마이페이지로 진입한다. 차량 카드에서 감지 준비 중·연결 확인 실패·블루투스 꺼짐·연결/해제 상태를 구분하고 권한·기기 오류는 필요한 때만 안내한다.

- 홈이 보이는 동안 등록 차량 연결이 해제되면 새 주차 건의 위치 확인 화면으로 자동 이동한다. 뒤로 돌아온 진행 건은 이어가기 버튼을 유지하며 자동 이동을 반복하지 않는다.
- 홈 진입 시 최근 주차 위치와 관계없이 휴대폰 GPS를 조회하고 현재 위치를 지도 중심에 표시한다. 최근 주차 차량 표시는 별도로 유지한다.
- 지도는 손가락으로 이동하고 두 손가락으로 확대·축소할 수 있다. 정보를 조회하거나 지도를 움직이는 동작만으로 주차 분석을 시작하지 않는다.
- 하단 정보 패널은 중간 높이로 시작하며 상단 손잡이를 위아래로 끌어 접힘·중간·펼침 높이로 조정한다. 손잡이를 눌러서도 높이를 바꿀 수 있고 내부 정보는 별도로 스크롤한다.
- 패널 높이에 맞춰 지도 표시 영역을 조정하여 현재 지도 중심이 패널에 가려지지 않게 한다. 패널 오른쪽 위의 현 위치 버튼은 패널과 함께 이동하며 GPS를 다시 조회한 뒤 현재 위치로 지도를 맞춘다. 같은 좌표에서도 재정렬한다.
- 위치 조회 중에는 버튼에 진행 상태를 표시하고 중복 조회를 막는다. 위치 권한·GPS·측위 실패는 사유를 표시하며 예시 좌표를 현재 위치로 표시하지 않는다.

### 지도와 장소 검색

- 지도는 Android 카카오 지도 SDK를 우선 사용하며 모듈이 없는 빌드·웹에서는 기존 타일 지도를 사용한다. 지도 엔진과 화면의 핀·위험 구역·하단 패널은 분리한다.
- 지도 탭·위치 확인·GPS 실패 후 수동 지정은 카카오 로컬 검색(상호·건물명은 키워드, 도로명·지번은 주소 검색)을 사용한다. REST API 키가 없는 빌드는 Android 지오코더 주소 검색을 쓴다. 용인시 여부는 검색어가 아닌 결과의 실제 주소로 판정한다.
- 이름·주소로 목록을 필터링하고 결과 선택 시 좌표·핀을 전달한다. 검색 중·결과 없음 상태를 제공한다.
- 지도 건수 토글은 서버가 제공한 구역별 신고 건수 표시를 제어한다.
- 지도와 범례에서 1단계 구역은 서버 반경 그대로의 회색 원으로 표시하고 시설 위치 핀은 따로 두지 않는다. 원을 최소 화면 크기로 확대하지 않는다. 2단계 주황 격자도 서버 칸 크기를 그대로 적용한다. 분석 결과의 강조색은 별도로 관리한다.
- Android 카카오 지도에서는 용인시 행정경계 밖을 반투명 회색으로 덮어 서비스 지역을 구분한다. 안내 문구는 두지 않으며, 이 경계는 표시용이고 지원 지역 판정은 주소 조회 결과를 따른다.
- 지도 표시와 타이머·모달·카드·탭은 분리한다. 위치·마커·구역은 공통 좌표 데이터로 관리한다.

### 주변 주차장

하단 목록 시트는 홈과 같은 공통 지도 시트를 사용한다. 중간 높이로 시작하고 손잡이를 위아래로 끌거나 눌러 접힘·중간·펼침으로 조절한다. 상단 위치 기준과 GNB를 가리지 않으며, 시트 높이에 맞춰 지도 표시 영역도 함께 조정한다. 시트 손잡이의 드래그와 주차장 목록의 스크롤은 독립적으로 처리한다. 제목·정렬·필터는 목록 위에 유지하고 접힘에서는 이 조작 영역을 중심으로 보여준다. 접힌 상태에서 지도 핀을 선택하면 중간 높이로 펼치며 해당 주차장 상세를 열고 목록도 해당 항목으로 스크롤한다. 펼친 상태에서 핀을 선택해도 시트 높이를 줄이지 않는다. 높이 조절로 반경·정렬·필터·선택 상태를 초기화하지 않는다.

주차 위치를 기준으로 반경·필터를 적용하고 결과 없음 안내를 제공한다. 500m에서 결과가 없는 경우 1km 확대 안내와 재조회 흐름을 구성한다. 주차장 유형·거리·요금·운영 상태는 서버 응답으로 표시한다. 유형 누락·미지원 값은 구분 정보 없음으로 표시하고 공영 필터에서 제외한다. 기본 목록은 운영시간 미상·운영 종료도 포함하며 운영 중 필터는 기본 OFF다. 사용자가 필터를 켠 경우에만 확인된 영업 중 주차장을 고른다. 영업 여부는 한국 시각으로 주기적으로 다시 계산하고 앱 복귀 시에도 갱신한다. 필터로 결과가 없으면 반경 확대와 함께 필터 초기화를 제공한다. 목록과 지도에서 선택한 주차장 핀에는 `180m`처럼 직선 거리를 표시하고, 실제 길안내는 외부 지도에서 제공한다. 도보 시간은 표시하지 않으며 타입에도 두지 않는다. 별도 AI 추천 기능은 제공하지 않는다.

목록 상단 정렬 드롭다운은 `가까운 순`(기본)·`무료 우선`을 제공한다. 무료 우선은 `feeType=FREE`인 주차장을 먼저 배치하고, 각 그룹 안에서는 거리 오름차순을 유지한다. 혼합 요금·요금 정보 없음은 무료로 간주하지 않는다. 반경·유형·운영 중 필터와 함께 적용하며 정렬 변경 시 목록 상단으로 이동하고 첫 항목을 기본 선택한다. 메뉴는 항목 선택·바깥 터치·Android 뒤로 가기로 닫힌다. 무료 주차장 여부를 임의로 채우지 않는다.

목록은 기본적으로 모두 접힌 상태이며 이름과 유형·직선 거리·요금 구분을 각각 건물·이동 방향·카드 아이콘과 함께 표시한다. 요약을 누르면 해당 주차장 한 곳만 상세가 펼쳐지고 다시 누르면 접힌다. 지도에서 핀을 선택해도 해당 상세를 연다. 상세는 요금 안내와 이용 정보로 나누고, 기본/추가요금·정기권·결제방법·주소·운영시간·운영 상태·주차 면수를 항목별로 표시한다. 공유·길안내 버튼은 펼친 영역 하단에 둔다. 반경·필터·정렬 변경 시 상세는 접는다. 기본 지도 선택과 상세 펼침 상태는 구분하여 첫 주차장이 자동으로 펼쳐지지 않게 한다.

서버 `feeInfo`가 `항목명: 값; 항목명: 값` 형식이면 알려진 항목을 나누어 보여준다. 기본·추가요금은 시간과 금액을 묶고, 금액에 원과 천 단위 구분을 적용한다. 정보 없음은 별도로 표시하고 알 수 없는 문구·중복 항목은 버리지 않는다. 0원 값을 무료 구분으로 바꾸거나 단위가 명확하지 않은 1일권 적용시간을 임의로 해석하지 않는다.

공유는 OS 공유 창을 열며 메시지를 자동 전송하지 않는다. 길안내와 외부 검색은 실제 카카오 지도 링크를 연다.

| 분석 실패      | 당시 위치·주차 시각·실패 설명            | `다시 분석하기` 제공          |

- 초기 필터는 `전체`이며 좁은 화면에서는 가로 스크롤 행을 사용한다. 서버 최신 최대 100건에 기기 보관 기록을 병합하고 오래된 기록·직접 응답을 제거하지 않는다. 조회 범위 안내는 100건 이상일 때만 표시한다.
- 기록 자체가 없는 경우와 현재 필터의 결과가 없는 경우를 구분한다.
- 재시도 중 중복 요청을 막고 새 결과 확정 전 기존 저장 결과를 보관한다.
- 뒤로 가면 보던 필터·스크롤 위치로 복귀한다. 갱신 결과가 현재 필터와 다르면 해당 필터 목록에서 제외한다.
- 실제 과거 시점 재분석의 제공 범위는 추후 API 명세와 대조한다.

## 4. 리포트

주차 위치·시각·결과 상태, 위험 근거·출처, 제공 가능한 신고·단속 이력과 시간대 차트, 사용자 횡단보도 응답, 주변 주차장 진입을 표시한다.

정보 부족·분석 실패는 별도 설명과 재시도를 제공한다. 데이터가 없는 통계·근거·법정 수치는 미제공으로 구분한다. 위험 판정과 리포트 수치는 서버 응답을 사용한다.

3단계 결과는 배지·기록 필터에 `위험 정보 없음`, 리포트 제목에 `위험 정보가 없어요`, 설명에 `이 위치에서 주차 금지 시설 근접이나 신고 집중 위험이 확인되지 않았어요.`를 쓴다. 이전에 저장한 기록도 같은 표시 문구를 적용하며 판정·근거·통계는 유지한다.

## 5. 재탑승 사후 설문

| 항목                | 정책                                                                            |

건너뛰기는 설문 응답값이나 설정 OFF로 처리하지 않는다. 다음 대상 주차에는 기존 설정에 따라 새 설문을 제공한다. 취소된 현재 주차는 설문 대상이 되지 않으며, 이전 완료 위험 기록의 대상 여부는 별도로 판단한다. 응답은 주차별 사용자 응답로 보관하고 실제 제출·집계·학습은 후속 연동으로 둔다.
