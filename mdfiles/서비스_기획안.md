# 세울까말까 — 서비스 기획안

기획 버전: 2026.11.07

대상: 용인시 운전자 · Android

구현 단계: 외부 연동 전 프론트엔드 데모 · 협업 초기 세팅

## 1. 서비스 개요

**세울까말까**는 운전자가 주차 위치를 확인하면 불법주정차 위험과 근거를 앱에서 살펴보고 주변 주차장을 찾을 수 있는 서비스다.

등록 차량의 블루투스 연결 해제를 주차 추정 이벤트로 활용한다. 사용자가 위치를 확인·보정하고 횡단보도 질문에 응답하면 해당 위치의 위험 분석 결과를 상세 리포트로 제공한다. 목적지를 미리 입력할 필요는 없다.

## 2. 사용자 가치

- 차량을 세운 뒤 위치를 간단히 확인하고 주차 위험을 살펴본다.
- 금지 구역·신고·단속 경향 등 판단 근거를 구분해 확인한다.
- 주변 공영·민간주차장을 대안으로 탐색한다.
- 위험 표시가 없는 주차까지 기록에서 다시 확인한다.

위험 정보는 참고 자료이며 안전·합법 주차를 보장하지 않는다. 정보가 부족하거나 분석에 실패한 경우는 별도 상태로 안내한다.

## 3. 이용 흐름

1. 카카오 로그인 후 권한 안내·온보딩을 확인하고 차량 블루투스 기기 1개를 등록한다.
2. 등록 차량의 연결이 해제되면 앱에서 주차 위치 확인을 진행한다.
3. GPS 위치를 확인·보정한다. 위치 조회 실패 시 직접 지정한다.
4. `이 위치가 맞아요` 또는 15초 타이머로 위치 선택을 마친다.
5. 횡단보도 위 또는 10m 이내 여부에 예/아니요로 응답한다.
6. 분석 결과와 근거를 확인하고 필요한 경우 주변 주차장을 찾는다.
7. 주차 내역을 기록에서 확인한다. 위험 리포트가 있던 주차는 재탑승 후 앱에서 선택적 단속 설문을 제공한다.

수동·자동 확정 모두 횡단보도 응답 후 분석한다. 완료 전 등록 차량이 재연결되면 진행을 취소한다. 시간·취소·복원의 상세 조건은 [주차 확인 명세](../mdfiles/02_주차확인_상세.md)를 따른다.

## 4. 주요 기능

| 기능          | 내용                                                              |
| ------------- | ----------------------------------------------------------------- |
| 홈            | 등록 차량·연결 상태, 최근 주차, 진행 중 위치 확인과 이어가기      |
| 지도          | 위험 구역·신고 건수 표시, 장소 이름·주소 검색과 위치 확인         |
| 위치 확인     | GPS 위치·핀 보정, 15초 타이머·게이지·시간 연장·재측정·수동 확인   |
| 횡단보도 확인 | 위치 선택 종료 후 예/아니요 모달                                  |
| 위험 리포트   | 결과 상태, 위험 근거·출처, 제공 가능한 통계·시간대 경향           |
| 주변 주차장   | 거리순 목록, 반경·운영 상태·유형 필터와 지도 핀                   |
| 기록          | 당시 위치·주차 시각·결과, 상태별 필터, 정보 부족·분석 실패 재시도 |
| 마이페이지    | 차량 변경·권한 안내·사후 설문 설정·계정 동작                      |
| 사후 설문     | 이전 위험 주차의 단속 여부 응답·건너뛰기                          |
| 데모 설정     | 외부 연결 없이 시나리오 선택·초기화                               |

기본 탐색은 **홈 / 지도 / 주변 주차장 / 기록 / 마이페이지** 5탭이다. 앱 이용에는 로그인과 차량 등록 완료가 필요하다.

## 5. 위험 분석과 정보 구성

최종 서비스는 확정 위치·시간·사용자 응답과 확보 가능한 공공데이터를 활용한다.

| 정보 영역      | 구성                                        |
| -------------- | ------------------------------------------- |
| 주차 위치      | 확인한 좌표·주소·주차 시각                  |
| 금지 구역      | 관련 시설물·구역과 확인 가능한 근거         |
| 신고·단속 경향 | 지역·요일·시간대별 제공 가능한 이력         |
| AI 분석        | 제공 가능한 위험도·신고 집중도 등 참고 결과 |
| 횡단보도       | 사용자 응답을 별도 출처로 표시              |
| 주차 대안      | 주변 주차장의 위치·거리·요금·운영 정보      |

실제 AI 모델·격자·점수·등급 산정 기준과 데이터 가용성은 미정이다. 법적 금지 여부의 규칙과 통계·AI 경향은 구분한다. 이번 단계는 예시 결과를 제공하며 실제 분석·집계로 표시하지 않는다.
