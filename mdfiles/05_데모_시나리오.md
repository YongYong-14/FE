# 세울까말까 — 데모 시나리오

기준일: 2026-11-07 · 시연 구성 기본안 · 전체 시나리오 구현 전

제품 정책은 [공통 정책](00_공통정책.md), 주차 진행은 [주차 확인 상세](02_주차확인_상세.md)를 따른다. 아래 시연 그룹은 기존 기능을 검증하기 위한 구성이다.

## 1. 시연 메뉴

- 진입: 로그인·차량 등록 후 **마이페이지 맨 아래 → 데모 설정**.
- 구성: 시나리오 선택, 다음 응답·이벤트 준비, 데모 초기화.
- 시나리오 선택은 앱 공통 상태와 모의 응답을 바꾼다. 실제 이용 화면을 거쳐 결과를 확인한다.
- 시나리오 준비만으로 등록 차량·기록을 일괄 삭제하거나 현재 진행을 덮어쓰지 않는다.
- 데모 권한 상태는 권한 안내·마이페이지·거부 배너가 공유한다. 실제 OS 설정과 구분한다.

## 3. 예외 상태 준비

| 상황                     | 실행 방식                                                                                     |
| ------------------------ | --------------------------------------------------------------------------------------------- |
| 첫 실행                  | 초기화 확인 후 로그인 → 안내·온보딩 → 차량 등록 → 홈                                          |
| 로그인 실패              | 다음 로그인 실패를 준비한 뒤 로그아웃·로그인. 차량·기록은 보관하고 재시도로 정상 흐름 확인    |
| 기기 목록 없음·등록 실패 | 차량 변경에서 같은 등록 화면의 예외 재현. 새 등록 성공 전 기존 등록 유지                      |
| 결과 예시                | 다음 분석 응답 선택 후 정상 위치 확인·횡단보도 응답을 거쳐 진입                               |
| 모달·분석 중 재연결      | 시작 전에 발생 단계를 예약하고 해당 단계에서 이벤트 발생. 모달의 뒤로 가기 규칙을 바꾸지 않음 |
| 실패 후 재시도           | 일회성 실패 뒤 정상 또는 다음 선택 응답 제공                                                  |
| 중복·취소                | 진행 상태·타이머 하나 유지. 취소·초기화·탈퇴 후 예약 이벤트·늦은 응답 무효화                  |

위치·횡단보도 응답·차량 등록의 정상 진입 조건을 우회하지 않는다. 공유·길안내·약관·탈퇴 등 보조 화면은 [화면 설계](01_화면_및_디자인.md)의 기본안을 적용한다.

## 4. 데모 초기화

| 요소        | 문구·동작                                                                                |
| ----------- | ---------------------------------------------------------------------------------------- |
| 제목        | 데모를 초기화할까요?                                                                     |
| 설명        | 로그인 상태, 등록 차량, 주차 기록, 설문과 설정이 처음 상태로 돌아가요.                   |
| 버튼        | 취소 / 초기화                                                                            |
| 초기화 범위 | 앱 소유 로그인·차량·기록·설문 응답/건너뛰기·설정·데모 권한·안내 상태·진행 상태·예약 작업 |
| 초기화 후   | 첫 실행 로그인. 사후 설문 기본 ON                                                        |
| 취소        | 데이터 유지                                                                              |

초기화는 실제 카카오 계정·서버 데이터·휴대폰 전체 데이터·OS 권한을 변경하지 않는다.
