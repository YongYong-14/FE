# 세울까말까 — 팀 공유 설계 판단

기준일: 2026-11-07 · 프론트 기획안 · 구현 전

공유 범위는 **횡단보도 응답 대기**와 **완료 전 차량 재연결 시 취소** 두 주제다. 아래 정책은 현재 프론트 구현 기준이며 팀 전체 승인·실동작 검증 완료를 뜻하지 않는다. 비교 대안은 채택 기능에 포함하지 않는다.

## 1. 자동 확정 후 횡단보도 응답 처리

**채택안: 수동 확인과 15초 자동 확정 모두 횡단보도 모달의 예/아니요 응답 후 분석한다.**

타이머 만료는 위치 선택 단계의 종료다. 응답이 없으면 분석을 대기하며, 기본값을 저장하거나 질문을 생략하지 않는다. 화면 꺼짐·다른 앱 사용 중에는 타이머가 계속 흐르고, 만료 후 응답 대기를 유지한다. 앱을 강제로 열지 않으며 복귀 시 모달을 표시한다.

| 방안                            | 처리                                             | 고려 사항                                          |
| ------------------------------- | ------------------------------------------------ | -------------------------------------------------- |
| 응답 후 분석 — 채택             | 예/아니요 응답을 기다린 뒤 분석                  | 실제 응답 확보. 사용자가 돌아오지 않으면 분석 대기 |
| 미응답을 미확인으로 유지 — 비교 | 다른 항목을 분석하고 횡단보도는 확인 불가로 표시 | 자동 진행 가능. 미확인 항목을 명확히 표시해야 함   |
| 미응답을 아니요로 간주 — 비교   | 부정 응답을 기본 처리하고 분석                   | 응답 부담 감소. 실제 사용자 응답과 다를 수 있음    |

## 2. 완료 전 차량 재연결 시 취소

**채택안: 등록 차량이 위치 확인·횡단보도 응답 대기·분석 중 재연결되면 현재 절차를 취소하고 홈으로 돌아간다.**

- 홈에서 이어가기를 기다리는 건에도 적용한다.
- 타이머·게이지·모달 대기·분석·이어가기·복원 상태를 정리한다.
- 늦게 도착한 응답이 화면·기록을 다시 생성하지 않도록 처리한다.
- 취소한 건의 새 결과·새 기록은 남기지 않으며 이전 완료 기록은 유지한다.
- 취소를 위험 미탐지·정보 부족·분석 실패로 저장하지 않는다.
- 사용자 뒤로 가기로 모달을 닫는 것과 차량 재연결에 따른 절차 취소는 별개다.

이 정책은 재연결 이후 불필요한 미완료 절차와 기록이 남는 일을 막기 위한 것이다. 재연결이 실제 미주차를 증명한다는 의미는 아니다.

| 방안                  | 처리                                     | 고려 사항                                                 |
| --------------------- | ---------------------------------------- | --------------------------------------------------------- |
| 완료 전 취소 — 채택   | 현재 절차 종료·홈 복귀·새 결과/기록 없음 | 재연결 시 미완료 흐름이 종료됨                            |
| 진행 상태 유지 — 비교 | 응답 대기 또는 분석을 계속하고 기록      | 절차를 계속할 수 있으나 불필요한 확인·결과가 남을 수 있음 |

이번 단계는 데모 이벤트로 재현한다. 실제 Android 이벤트 수신·복원, API 처리 중 취소·늦은 응답·서버 저장은 후속 연동에서 검증한다.
