# 세울까말까 — API 연동 현황

기준일: 2026-11-09 · 기준 명세: API 명세 v0.11 (ERD v5.1) · 백엔드 저장소 `YongYong-14/BE` 응답 레코드와 대조

## 1. 실행 모드

`EXPO_PUBLIC_API_BASE_URL` 값으로 데모와 서버 연결을 고른다. 화면 코드는 같고 `src/services/index.ts`가 구현을 바꾼다.

| 모드      | 설정                                      | 동작                                                  |
| --------- | ----------------------------------------- | ----------------------------------------------------- |
| 데모      | `EXPO_PUBLIC_API_BASE_URL` 비움           | 기존 모의 응답·데모 설정 시나리오 그대로              |
| 서버 연결 | `EXPO_PUBLIC_API_BASE_URL=https://<서버>` | 명세의 서버 API 호출. `/api/v1`은 자동으로 붙는다     |
| 목 서버   | `npm run web:mock`                        | 명세대로 동작하는 로컬 목 서버(4000)와 웹을 함께 실행 |

```bash
npm run web:mock    # 목 API 서버 + 웹(서버 연결 모드)
npm run mock:api    # 목 API 서버만
npm run test:api    # 목 서버 계약 검사(임시 포트에 서버를 띄워 검사)
npm run web         # 웹(데모 모드 또는 .env의 서버 주소)
```

카카오 SDK는 아직 붙이지 않았다. 서버 연결 모드의 로그인은 `EXPO_PUBLIC_KAKAO_ACCESS_TOKEN`의 개발용 카카오 토큰을 `POST /auth/kakao`로 보낸다. 목 서버는 `mock-kakao-<아무값>`을 받는다. 실제 서버는 카카오가 발급한 실제 토큰이 필요하다.

웹에서 실제 서버를 부르려면 백엔드의 허용 Origin(CORS)에 웹 주소(예: `http://localhost:8081`)가 있어야 한다.

## 2. 엔드포인트와 앱 연결 지점

| API                                 | 앱에서 부르는 곳                          | 비고                                                                                                         |
| ----------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| POST /auth/kakao                    | 로그인 화면 → `accountService.signIn`     | 토큰 저장, 미동의 약관으로 동의 화면 이동                                                                    |
| POST /auth/refresh                  | `services/api/client.ts` 자동             | 만료 30초 전·401 TOKEN_EXPIRED에서 한 번만(동시 요청 합침)                                                   |
| POST /auth/logout                   | 마이페이지 로그아웃, 데모 초기화          | 실패해도 기기 로그인은 끝낸다                                                                                |
| GET /me                             | 앱 시작 시 로그인 복원                    | 약관 최신 이력으로 미동의 판단                                                                               |
| POST /me/agreements                 | 약관 동의 화면(`(onboarding)/agreements`) | TERMS·PRIVACY·LOCATION_SERVICE, 버전 `2026-11-06-v1`                                                         |
| DELETE /me                          | 마이페이지 회원 탈퇴                      | 성공한 뒤에만 기기 데이터 삭제                                                                               |
| POST /webhooks/kakao/unlink         | 앱은 호출하지 않음                        | 카카오 서버 전용. 목 서버에만 구현                                                                           |
| GET /vehicle                        | 로그인·복원, 홈 진입                      | 서버에 차량이 없으면 차량 등록으로 이동                                                                      |
| PUT /vehicle                        | 차량 등록·변경                            | 페어링 기기의 이름·MAC·종류. 409면 다시 조회 후 1회 재시도                                                   |
| GET·PATCH /notification-settings    | 마이페이지 알림                           | 1단계는 항상 켜짐, 2단계·야간만 변경                                                                         |
| POST /parking-events                | 위치 확정 → 횡단보도 응답 뒤              | 아래 3절                                                                                                     |
| GET /parking-events/latest          | 홈                                        | 최근 주차·신고 데이터 기간(dataPeriod)                                                                       |
| GET /parking-events                 | 기록 탭, 홈                               | 1단계·2단계 필터는 `level`, 나머지는 앱이 거름                                                               |
| GET /parking-events/{id}            | 결과·기록 상세                            | 근거·신고 집중 시간(peak). 주소는 3초 뒤 한 번 더 읽음                                                       |
| PATCH /parking-events/{id}/delivery | 앱 안 위험 알림을 띄운 직후               | 중복 표시는 기기에 기록해 막음                                                                               |
| GET /parking-lots/nearby            | 주변 주차장 탭                            | 최근 주차 위치(없으면 현재 위치) 기준, 자동 1km 확장 안내                                                    |
| GET /map/risk-zones                 | 지도 탭                                   | 보이는 범위를 약 1.8km 고정 칸으로 나눠 조회(한 변 2km 제한), 이동·확대 후 0.25초 뒤 새 칸만 요청, 10분 캐시 |
| GET /health                         | 데모 설정 → 서버 연결 확인                |                                                                                                              |

코드 위치: 요청·응답 자료형 `src/services/api/types.ts`, 엔드포인트 `endpoints.ts`, 공통 요청·토큰 `client.ts`, 응답 변환·화면 문구 `mappers.ts`, 기능별 구현 `services.ts`.

## 3. 주차 판정 흐름

- 앱이 `clientEventId`(UUID)를 만들고 제출값 전체를 진행 상태에 저장한다. 재시도·앱 재실행 뒤에도 같은 값으로 보낸다.
- 횡단보도 응답은 앱 안에서만 쓰고 요청에 넣지 않는다(서버는 모르는 필드를 400으로 거절).
- GPS 정확도: 15m 이내만 15초 자동 확정(AUTO), 15~50m는 직접 확정(CONFIRMED·ADJUSTED), 50m 초과는 GPS를 쓰지 않고 위치를 직접 고른다.
- 확정 위치가 GPS에서 200m를 넘으면 앱이 먼저 막고, 서버가 400 ADJUST_DISTANCE_EXCEEDED·AUTO_CONFIRM_NOT_ALLOWED를 주면 위치 확인으로 되돌린다.
- 판정 FAILED(1회)는 같은 키로 한 번 자동 재전송한다. 2회째도 FAILED면 기록만 남긴다.
- 409 IDEMPOTENCY_KEY_REUSED는 새 키로 한 번 다시 보낸다. 403 LOCATION_CONSENT_REQUIRED는 동의 화면으로 보내고 동의 후 같은 요청을 이어서 보낸다. 404 VEHICLE_NOT_FOUND는 차량 다시 등록을 안내한다.
- 네트워크·서버 오류는 기록을 만들지 않고 "다시 시도"를 보여준다. 같은 키라 중복 저장되지 않는다.
- 결과 표시: SUCCEEDED 1·2단계, 3단계는 "알림 대상 아님", PARTIAL은 "판단 불가"로 보여주고 "안전"이라고 쓰지 않는다.
- 알림: `notify.decision`이 SEND이고 `expiresAt` 전이며 처음인 주차만 앱 안 알림으로 띄우고 delivery를 보고한다. 문구는 앱이 정하고 서버 title·body는 쓰지 않는다.

## 3-1. 기기 저장

- 서비스 토큰은 AsyncStorage(`auth-tokens`)에 둔다. 운영 전에는 OS 보호 저장소(expo-secure-store, 새 개발 빌드 필요)로 옮긴다.
- 기록은 서버 목록이 기준이다. 기기에는 횡단보도 응답·원래 제출값을 함께 보관하고 서버 목록과 병합한다.
- 데모 초기화·탈퇴는 토큰·기록·진행 상태·표시한 알림 기록을 모두 지운다.

## 3-2. 지도 탭

- 지도 탭은 OpenStreetMap 타일(`https://tile.openstreetmap.org/{z}/{x}/{y}.png`)을 배경으로 쓰고 화면에 출처(© OpenStreetMap)를 표시한다. 다른 주소는 `EXPO_PUBLIC_MAP_TILE_URL`로 바꾼다. 공용 타일 서버는 시연·개발용이며, 운영 전에는 지도 SDK나 별도 타일 서비스로 바꾼다.
- 끌어서 이동, 확대·축소 버튼, 웹 마우스 휠, 휴대폰 두 손가락 확대를 지원한다. 확대 단계는 14~18이다.
- 위험 구역은 보이는 범위를 약 1.8km 고정 칸으로 나눠 `GET /map/risk-zones`로 받는다. 같은 칸은 10분 동안 다시 받지 않는다.
- 신고 건수 말풍선은 확대 15.5 이상에서만 보이고, 겹치면 건수가 많은 칸을 먼저 칸 위·아래에 놓고 나머지는 숨긴다.

## 4. 아직 데모인 기기 기능·외부 SDK

서버 API와 별개로 실제 연결이 남은 항목이다.

| 대상          | 현재                                                                                                   | 후속                                                                                                  |
| ------------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| 카카오 로그인 | 개발용 토큰(`EXPO_PUBLIC_KAKAO_ACCESS_TOKEN`)                                                          | 카카오 SDK 로그인 결과의 액세스 토큰으로 교체(`apiAccountService.signIn`)                             |
| 블루투스      | 데모 기기 목록·연결 해제 버튼                                                                          | 페어링 기기 조회·연결 해제 이벤트·백그라운드 수신                                                     |
| GPS           | 데모 좌표·정확도(데모 설정에서 32m·80m 선택 가능)                                                      | 실제 좌표·정확도, 마지막 좌표(lastKnownLocation)                                                      |
| 지도          | 지도 탭: OpenStreetMap 타일 위에서 끌기 이동·확대(버튼·휠·두 손가락), 다른 화면: 일러스트 위 비율 배치 | 지도 SDK(카카오맵 등)를 정하면 `shared/map/GeoMap.tsx`만 교체. 타일 주소는 `EXPO_PUBLIC_MAP_TILE_URL` |
| 장소 검색     | 데모 장소 목록                                                                                         | 카카오 검색 직접 호출(서버 API 없음)                                                                  |
| 알림          | 앱 안 알림 배너                                                                                        | OS 로컬 알림(expo-notifications, 새 개발 빌드 필요)                                                   |
| 용인시 판별   | 데모 장소의 지원 지역 값                                                                               | 행정구역 판별(서버는 용인 밖을 PARTIAL로 돌려줌)                                                      |
