# 세울까말까 — 온보딩과 실서비스 실행 기준

기준일: 2026-11-11 · Android

## 로그인 후 진입

1. 실제 카카오 SDK 인증 후 `POST /auth/kakao`로 서비스 토큰을 받는다.
2. 서버가 필수 약관 미동의를 반환하면 기존 동의 화면에서 동의한 뒤 진행한다. 약관 원문은 `/terms`에서 볼 수 있다.
3. 이 계정의 기기 권한 안내를 완료하지 않았다면 권한 안내를 표시한다.
4. 등록 차량이 없으면 휴대폰에 페어링된 블루투스 기기 중 하나를 선택해 `PUT /vehicle`로 등록한다. 등록이 성공해야 홈에 진입한다.
5. 동일 계정의 완료된 온보딩·서버 차량은 복원한다. 다른 계정 로그인 시 기존 안내 완료 상태를 그대로 적용하지 않는다.

## 권한

- ‘권한 허용하기’는 실제 위치(앱 사용 중)와 근처 기기 권한을 요청한다.
- 위치가 앱 사용 중 허용이면 별도 설명 후 Android의 백그라운드 위치 설정으로 이동한다. 항상 허용을 거절해도 선택을 존중한다.
- ‘나중에 설정’은 안내만 완료하며 OS 권한을 허용한 것으로 저장하지 않는다. 다음 차량 등록에서 근처 기기 권한이 없으면 설정 안내를 제공한다.
- 카드에서 앱 권한/배터리 최적화 설정으로 진입할 수 있다. 배터리 예외는 선택이다.
- 실제 페어링·블루투스 연결은 휴대폰 설정에서 한다. 앱은 선택한 기기를 차량으로 등록하고 연결/해제를 감지한다.

## 실제 데이터 사용

- 서비스는 서버 API와 기기 서비스만 사용한다. 서버 주소 미설정·네트워크 실패·권한 거부 시 설정/오류/빈 상태를 표시한다.
- 모의 계정·정적 기기·가짜 GPS·예시 위험/신고 건수/주차장·실패 주입·예약 연결 이벤트·데모 설정/초기화 메뉴·로컬 목 서버는 제거한다.
- 수동 `EXPO_PUBLIC_KAKAO_ACCESS_TOKEN` 인증 경로를 사용하지 않는다. 기존 환경 변수에 남아 있어도 읽지 않는다.
- 홈·위치 확인·결과·주변 주차장의 정적 지도 일러스트는 실제 공통 지도로 바꾼다. Android는 준비된 카카오 SDK, 웹 등은 실제 OSM 타일을 사용한다.
- GPS 확인 전 용인시 지도 중심은 지도 시작점일 뿐 현재 위치·주차 위치 핀이나 주변 주차장 조회 기준으로 사용하지 않는다.
- 위치 확인 화면의 핀은 지도 표시 영역 중앙에 고정한다. 최초 GPS 위치·재측정·검색 결과를 중앙에 맞추고, 사용자가 지도를 움직인 뒤 멈춘 중앙 좌표의 실제 역지오코딩 주소를 조회한다. 조작·주소 확인 중 및 주소 조회 실패 시 이전 위치의 확정을 막고, 앱 안에서는 남은 타이머를 잠시 보관한다. 기존 GPS 기준 200m 보정 제한은 유지한다.
- 수동 주소 검색은 카카오 로컬 검색을 사용하고, REST API 키가 없는 빌드는 Android 지오코더를 쓴다. 빈 검색어에는 예시 장소를 제공하지 않는다.
- 공유는 OS 공유 창을 열고, 길안내/외부 검색은 카카오 지도 링크를 연다. 공유 메시지를 자동 전송하지 않는다.
- 이전의 가짜 계정과 예시 표시가 있는 기록은 실제 세션·기록으로 복원하지 않는다. 실제 계정·서버 기록은 유지한다.

## 개발용 차량 등록 건너뛰기

차량 등록 화면 하단의 ‘블루투스 등록 건너뛰기 (목업)’ 버튼은 개발 빌드에서만 제공한다. 이 버튼은 기기 선택·페어링·`PUT /vehicle` 호출 없이 홈으로 이동할 수 있도록 기기에 건너뛰기 상태만 저장한다. 서버 차량 ID나 연결 이벤트를 만들지 않으며 자동 주차 감지는 작동하지 않는다. 홈·마이페이지에 목업 상태를 표시한다. 서버 차량 조회가 비어 있어도 건너뛰기 상태를 유지하고, 로그아웃·재로그인·실제 차량 등록 시 해제한다. 릴리스 빌드는 이 상태로 진입을 허용하지 않는다. 다른 API·GPS·기록·지도 기능은 실제 연결을 유지한다.

## 미제공 항목

약관 원문은 전달되지 않아 디자인의 ‘내용 준비 중’ 안내를 유지한다. 사후 설문은 실제 사용자 응답을 기기에 저장하며 서버 제출 API가 없어 서버 제출·AI 반영 완료로 표시하지 않는다. Android 전용 기능을 웹에서 모사하지 않는다. GPS·블루투스·카카오 인증의 최종 동작은 실제 기기/계정으로 확인한다.
