## 작업 운영 규칙

- 작업 맥락은 `용용톤 프론트 개발`이며, 이 대화와 로컬 문서를 통해 유지한다.
- 현재 승인 범위는 협업 초기 세팅이다. Expo·공통 도구·보호 경로·5탭·데모 진입·저장 기반을 준비하며 상세 제품 기능·Figma 화면·실제 API 연동과 구분한다.
- 문서는 현재 기획과 구현 기준을 유지한다. 대화 순서·질문 이력·폐기된 제안을 누적하지 않는다.
- 명시적으로 확정된 기획과 구현 기본안, 추후 검토 사항을 구분한다. 기존 내용을 재확인하는 질문은 하지 않고 실제 충돌·진행 차단·중요한 우려만 확인한다.
- 팀 공유 문서는 현재 요청된 두 주제와 관련 정정만 반영한다. 일반 결정·구현 기본안은 자동 추가하지 않는다.
- API 명세서 수령 및 연동 지시 전에는 백엔드 자료·키·API·일정을 요청하지 않는다.
- Notion 작업은 매 작업 전에 사용할 계정을 확인한다. 명확한 계정 지정 없이 검색·조회·수정하지 않으며 이전 작업의 계정을 자동 적용하지 않는다.
